## 📖 Introduction

> As a programmer, I have always faced the same challenge whenever I wanted to start working: launching all the software I needed to begin coding. I usually had to open four or five different applications, which took time and effort. A few days ago, while learning **Batch Scripting**, I came up with an idea: Why not automate this process and save myself some time and energy? So, I got to work and started coding. Eventually, I decided to make my project publicly available for everyone to use.

<a id="what-is-scripting"></a>

## 👨🏻‍💻 What Is Scripting?

Scripting is a way to automate repetitive tasks by executing a single script file.

<a id="what-is-batch-script"></a>

## 🤔 What Is Batch Scripting?

Batch Scripting is a high-level interpreted scripting language and one of the simplest and most accessible ways to interact with Windows programmatically. Unlike modern languages that require a separate runtime environment and additional tools, Batch is built into the Windows operating system and is ready to run without requiring any additional software.

<a id="project-description"></a>

## 💬 Project Description

FastyWorkspace is an interactive tool that allows you to launch a collection of applications you use regularly — whether for programming, design, editing, research, or gaming — with just one click, instead of opening each application from its separate folder every time.

Simply provide the paths to the applications you want to use and choose a name for each workspace. From then on, whenever you're ready to start working, you can launch all the applications in that workspace with a single click.

## ▶️ How to Run

You can download and run FastyWorkspace using either of the following methods.

<a id="git-clone"></a>

### 1️⃣ Method 1: Clone the Repository (Git Clone)

1. Press **Win + R** to open the Run dialog.
2. Type **cmd** and press **Enter**.
3. Run the following command to navigate to your Desktop:

   ```bat
   cd %USERPROFILE%\Desktop
   ```

4. Run the following command to clone the repository:

   ```bash
   git clone https://github.com/Mohammad-Khiabani/FastyWorkspace.git
   ```

5. You will find the `FastyWorkspace` folder on your Desktop.

> **Prerequisite:** Git must be installed on your system to use this method.

<a id="download-zip"></a>

### 2️⃣ Method 2: Direct Download (Download ZIP)

1. Visit the [FastyWorkspace repository on GitHub](https://github.com/Mohammad-Khiabani/FastyWorkspace).
2. Click the **Code** button near the top of the page.
3. Select **Download ZIP** from the menu to start downloading the project.
4. Extract the downloaded ZIP file using an archive utility such as **WinRAR** or **7-Zip**.

### 🚀 Running the Application

1. Open the `FastyWorkspace` folder.
2. Run `FastyWorkspace.bat`.
3. Follow the instructions in the application menu to create your own **workspace**.
