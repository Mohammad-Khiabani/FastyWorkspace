## 📖 مقدمه : 
>  من به عنوان یک برنامه نویس همیشه هنگام شروع کار این چالش رو داشتم که نرم افزار های مورد نیازم رو لانچ کنم تا بتونم کدنویسی رو شروع کنم و معمولا باید چهار الی پنج نرم افزار رو لانچ میکردم و زمانی رو ازم میگرفت چند روز پیش که در حال یادگرفتن **batch Scripting** بودم یه ایده ای به ذهنم زد و گفتم چرا همین کارا رو به صورت اتوماتیک انجام ندم و مقداری زمان و انرژی رو برای خودم ذخیره نکنم؟پس دست به کار شدم و شروع به نوشتن کردم و در نهایت تصمیم گرفتم پروژه م رو برای استفاده عمومی در اینترنت قرار بدم.

<a id="what-is-scripting"></a>

## 👨🏻‍💻 اسکریپت نویسی چیست؟
اسکریپت نویسی راهی هست که با استفاده از اون میشه کارهای تکراری رو به صورت اتوماتیک و تنها با اجرای یک فایل انجام داد.

<a id="what-is-batch-script"></a>

## 🤔 batch script چیست؟
Batch Scripting یک زبان سطح بالای مفسریه و یکی از ابتدایی ترین و در دسترس ترین راه‌های تعامل برنامه‌نویسی‌شده با ویندوزه. برخلاف زبان‌های مدرن که نیاز به نصب محیط اجرا و ابزارهای جانبی دارن، Batch از دل خود سیستم‌عامل بیرون اومده و روی هر نسخه‌ای از ویندوز، بدون هیچ پیش نیازی، آماده‌ی اجراست.

## 🧱 کاربردها
- پشتیبان‌گیری و بازیابی فایل‌ها (Backup & Restore)
- مدیریت فایل‌ها و پوشه‌ها (File & Directory Management)

- مدیریت فرایندها و سرویس های ویندوز (Process & Service Management)
- کامپایل، اجرا و تست خودکار پروژه‌های نرم‌افزاری (Build & Test Automation)
- و ...

## 💬 توضیح پروژه: 
FastyWorkspace یک ابزار تعاملیه که به کمکش می‌تونید مجموعه‌ای از نرم‌افزارهای روزمره‌تون — از برنامه‌نویسی و طراحی گرفته تا ادیت، تحقیق و بازی — رو که معمولاً هر بار باید از پوشه‌های جداگانه اجرا کنید، تنها با یک کلیک باز کنید.

کافیه مسیر نرم‌افزارهای مورد استفاده‌تون رو بهش بدید و برای هر مجموعه یه نام انتخاب کنید. از اون به بعد، هر وقت خواستید شروع به کار کنید، با یه کلیک همه‌ی اون برنامه‌ها کنار هم اجرا می‌شن.

<a id="how-to-run"></a>

## ▶️ نحوه اجرا: 
برای دریافت و اجرای FastyWorkspace می‌توانید از یکی از روش‌های زیر استفاده کنید.

<a id="git-clone"></a>

### 1️⃣ روش اول: کلون کردن مخزن (Git Clone)

1. کلیدهای ترکیبی **Win + R** را فشار دهید.
2. عبارت **cmd** رو وارد کرده و **Enter** بزنید.
3. برای رفتن به دسکتاپ، دستور زیر رو اجرا کنید:
`cd %USERPROFILE%\Desktop`
4. برای دریافت مخزن، دستور زیر رو اجرا کنید تا فرآیند کلون کردن آغاز بشه.:
`git clone https://github.com/Mohammad-Khiabani/FastyWorkspace.git`
5. با رفتن به دسکتاپ میتونید فولدر FastyWorkspace رو پیدا کنید.

* پیش نیاز: برای استفاده از این روش، باید **Git** روی سیستم شما نصب باشد.

<a id="download-zip"></a>

### 2️⃣ روش دوم: دانلود مستقیم (Download ZIP) 
1. به صفحهٔ مخزن FastyWorkspace در GitHub بروید.
2. روی دکمهٔ Code که بالای صفحه قرار داره کلیک کنید.
3. در پنجره باز شده گزینه **Download ZIP** رو انتخاب کنید تا فرآیند دانلود آغاز بشه.
4. با استفاده از یک نرم افزار فشرده سازی مثل **Winrar** یا **7Zip** فایل رو از حالت فشرده خارج کنید.

### 🚀 اجرا
1. وارد پوشه **FastyWorkspace** بشید.
2. فایل **FastyWorkspace.bat** رو اجرا کنید.
3. مراحل نمایش داده شده در منوی برنامه رو دنبال کنید تا **Workspace** خودتون رو بسازید.
